# 半身演示

此 Mod 从 `robot_test` 的悬挂跑步测试移入录制轨迹，仅规划已接入的 19 个关节：腰部 3 个、左右髋俯仰各 1 个、双臂 14 个。左右腿其余 10 个关节和头部 2 个关节不参与测试目标或反馈检查。实机仅发送这 19 个关节的命令；半身仿真模型另保留头部 2 个关节，控制器发送含头部默认位姿的 21 关节命令。

| 按键 | 功能 |
| --- | --- |
| LB+B | 从初始姿态直接进入悬挂跑步 |
| X | 跑步中受控停止并返回初始姿态 |
| LB+Y | 从零位模式直接进入双臂行程测试；测试中再次按下受控停止并返回零位模式 |
| RB+B | 跑步或行程测试中平滑退出到初始姿态 |
| RB+Y | 跑步或行程测试中平滑退出到零位模式 |
| RB+A | 测试中紧急切换到零力矩 |

LB+A 不再触发本 Mod；遥控配置仍保留其原始输出供其他模式使用。

此 Mod 只有悬挂跑步和双臂行程两个状态，不再包含准备或待机状态。进入测试时，已接入关节反馈与对应起始姿态的最大偏差允许 10 度；退出回位的到位要求仍为 5 度。跑步从实测姿态用 0.5 秒平滑过渡到录制轨迹首帧后以 50 Hz 播放；受控停止后回到初始姿态。双臂行程从实测零位起步，测试中腰、髋保持 0 rad；受控停止后回到零位模式。退出按键先在当前测试状态内以不超过 60 度/秒的峰值速度回到目标角度，再用 0.3 秒平滑切换位置和 PD 增益；回位过程中可改按另一个目标键。LB+RB+B 不再绑定动作。反馈超过 0.2 秒未更新、控制周期中断超过 50 ms、位置命令越过软件限位，或姿态未到位时，会请求零力矩并锁定测试，重启控制程序后才能重新进入。

此单项跑步测试不包含原 B 顺序测试的电机温度监测；必须确认硬件温度保护和外部监控有效。录制轨迹在已接入关节中的最大相邻帧变化约为 0.22 rad（50 Hz），实机应先在可靠悬挂、周围无人的条件下检查运动幅度和电机跟踪。软件筛选和电机禁用掩码不能代替物理悬挂或硬件保护。

双臂行程测试沿用 `robot_test` 的双侧腕、肘、肩顺序和紧凑肘部姿态。按模型无碰撞范围预留 10 度、软件关节限位预留 2 度，逐段从低位移动到高位再返回；运动速度上限按 60 度/秒规划，状态以 50 Hz 运行。未接入的腿部关节不下发命令。段末双臂跟踪误差超过 5 度或归零失败时切零力矩。该测试不进行在线碰撞检测或温度监测；首次实机运行必须在可靠悬挂下逐段观察，确保双臂不会碰到机身、外物或人员。
