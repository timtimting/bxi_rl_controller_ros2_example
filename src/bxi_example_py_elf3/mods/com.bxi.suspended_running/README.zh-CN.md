# 半身悬挂跑步测试

此 Mod 从 `robot_test` 的悬挂跑步测试移入录制轨迹，仅使用已接入的 19 个关节：腰部 3 个、左右髋俯仰各 1 个、双臂 14 个。左右腿其余 10 个关节和头部 2 个关节不参与测试命令，也不要求这些关节的反馈。仿真和实机使用相同的 19 关节命令。

| 按键 | 功能 |
| --- | --- |
| LB+RB+Y | 从零力矩或初始姿态进入测试待机，3 秒回中位 |
| X | 待机时启动跑步；跑步时受控回中位并返回待机 |
| LB+RB+B | 从待机或跑步直接退出到零力矩 |

待机确认已接入关节回中位后才接受 X。跑步先切换到录制轨迹的起始姿态，再以 50 Hz 播放；待机与跑步状态均以 50 Hz 更新关节命令。反馈超过 0.2 秒未更新、控制周期中断超过 50 ms、位置命令越过软件限位，或回中位失败时，会请求零力矩并锁定测试，重启控制程序后才能重新进入。

此单项跑步测试不包含原 B 顺序测试的电机温度监测；必须确认硬件温度保护和外部监控有效。录制轨迹在已接入关节中的最大相邻帧变化约为 0.22 rad（50 Hz），实机应先在可靠悬挂、周围无人的条件下检查运动幅度和电机跟踪。软件筛选和电机禁用掩码不能代替物理悬挂或硬件保护。
